# Любимые фильмы

Небольшой персональный киножурнал на Flask, Jinja2 и CSS. JavaScript и внешние шрифты не требуются. Обложки созданы средствами CSS и типографики, это не оригинальные постеры.

## Запуск

Из каталога `movie_catalog`:

```sh
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m flask --app app run
```

На Windows используйте `.venv\Scripts\python` вместо `.venv/bin/python`.

## Проверка

```sh
.venv/bin/python -m unittest -v
```

Проверяются HTML/CSS, поиск, отправка отзывов, серверная валидация и экранирование пользовательского ввода.

## Поведение

- `GET /` — киножурнал.
- `GET /search?title=...` — подтверждение поискового запроса; настоящего поиска в базе нет.
- `POST /review` — проверка полей `title`, `rating` (1–5), `review` и подтверждение приёма. Отзывы не сохраняются.
- Ошибки ввода возвращают HTTP 400, успешные ответы — HTTP 200.

Исходные URL, методы и правила валидации сохранены. В `app.py` изменён только вывод ответов через шаблон с автоматическим экранированием Jinja2.

Макеты проверены в Chromium на ширинах 320, 390, 768 и 1440 px. Снимки находятся в `previews/`.
